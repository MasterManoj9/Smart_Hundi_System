

1. Backend Security & Configuration

- Masked the IoT API key in the JSON payload preview.

- Added a clear “Prototype data” indication.

4. Prototype Status & Page Badges
- Updated the sidebar status to “Prototype — Hardware integration under development”.
- Standardized the “Prototype” badge on Dashboard, Coins, Live Collection and Notes pages.
- Removed redundant “Simulation Mode” badges from Storage and Transactions pages.

5. UI Cleanup & Documentation Alignment
- Removed the placeholder/speculative “AI Note Detection” panel from the Notes page.
